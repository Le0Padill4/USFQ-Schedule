# Propuesta

USFQ-Schedule ayuda a estudiantes a consultar su avance curricular y comparar horarios válidos. El MVP enlaza malla, materias aprobadas, oferta, prerrequisitos y preferencias. La app se ejecuta sin costo con datos sintéticos y servicios locales; scraping solo se habilita tras confirmar autorización de una fuente oficial. No almacena datos personales reales.
