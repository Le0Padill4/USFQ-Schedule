# Seguridad

## Amenazas
Acceso a datos de otro usuario, inyección SQL, secretos en Git, oferta alterada, scraping abusivo y herramientas MCP que escriban o consulten fuera de alcance.

## Controles
Datos sintéticos; hash seguro de contraseñas; autorización por recurso; queries parametrizadas; rol MCP read-only; validación y límites; allowlist de herramientas; `.env` ignorado; revisión de dependencias y permisos mínimos. No se afirman controles hasta implementarlos y verificarlos.
