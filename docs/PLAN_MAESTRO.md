# Plan maestro

1. **Estructuras de Datos — 30 nov 2026, 23:59:** motor en Python, operaciones comparables, dos estructuras propias, invariantes, pruebas diferenciales, benchmarks, CSV, gráficos, informe y ZIP según CMP3002.

## Fases

### Fase 1 — Contratos y estructura (24–25 nov)
Acordar operaciones, escenarios, modelos, API y criterios. Preparar fixtures, versión lenta y esqueleto reproducible. Confirmar con el profesor que CMP3002 acepta trío; autorización indicada por el usuario, falta registrar evidencia si existe.

### Fase 2 — Implementación paralela (25–28 nov)
Integrante 1: grafo dirigido, prerrequisitos, BFS/DFS/topología y frontend. Integrante 2: AVL, API/BD, autenticación, MCP e importación de oferta autorizada. Integrante 3: generador, poda, ranking y benchmarks. Todos trabajan mediante PRs pequeños y contratos versionados.

### Fase 3 — Integración y entrega (28 nov–8 dic)
Integrar y validar 10.000 operaciones aleatorias; cerrar benchmarks académicos, CSV, gráficos, informe y ZIP antes del 30 nov. Después completar flujos web, CI/CD, seguridad, investigación, evidencias reales y release `v1.0` antes del 8 dic.

## Límite del MVP

Login de demostración, selección de carrera, malla, materias aprobadas, consulta de oferta, comprobación de prerrequisitos/cruces y generación de horarios. Scraping solo de fuente oficial permitida; si falta autorización, fixture sintético y adaptador pendiente. Planificar futuros semestres después del flujo principal.
