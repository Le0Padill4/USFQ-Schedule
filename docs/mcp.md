# MCP

Objetivo: servidor FastMCP local con transporte stdio y consultas permitidas para buscar materias, consultar prerrequisitos y leer oferta por término. Conexión PostgreSQL mediante usuario sin permisos de escritura; validación de argumentos y límites de resultados. No exponer puerto público ni permitir SQL recibido del agente. Implementación y pruebas aún pendientes.

La propuesta de servidor local de carreras se describe en
[estado MCP](estado/integrante_2_mcp.md) y su justificación en
[dependencia MCP](estado/dependencias_mcp.md).
